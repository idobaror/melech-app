# מלך הקסטות — אפליקציית צוות

דף אחד (סטטי) מול API בפרויקט Apps Script **נפרד**: `scripts/melech-app-api`.
לא תלוי ולא נוגע בפרויקט הקיים `scripts/melech-hakasetot`.

## קבצים
- `config.js` — כתובת ה-API ו-Google Client ID (הקובץ היחיד לעריכה)
- `app.js` — התחברות, קריאות API, ניווט
- `pages.js` — בית, אירועים, פנייה חדשה, פרטי אירוע (שיבוץ + וואטסאפ, משוב), יומן, הצעת מחיר (PDF ממוזג, וואטסאפ/מייל), פרוטוקול הקמה, סיכום שבועי, הגדרות (משתמשים, מוצרים)
- `app.css` — עיצוב
- `manifest.webmanifest`, `sw.js`, `icons/` — התקנה בטלפון (PWA)

## הרצה מקומית בלי Google (נתוני דמו)
```
cd scripts/melech-app-api
node test/devserver.js      # http://localhost:8080 — בוחרים משתמש דמו לפי תפקיד
node test/run.js            # 106 בדיקות API מקצה לקצה (כולל מיזוג PDF אמיתי)
```

## שלבים
1. ✅ פיתוח + בדיקות מול הדמיה
2. ⬜ סביבת בדיקה אמיתית: פרויקט Apps Script חדש + עותק של הגיליון (`setupTestEnvironment`)
3. ⬜ התחברות Google אמיתית מ-localhost מול סביבת הבדיקה
4. ⬜ GitHub Pages
5. ⬜ מעבר לייצור (`switchToProduction` — נעול כרגע)
